# 商法实训室 Business Law Studio

云南财经大学《商法导论》全课程双语学习资源。

## 内容

- 16个内容单元，与课程大纲一一对应。
- 192张中英概念词卡，含定义与双语例句。
- 32个原创模拟案例，含事实、问题、分步参考分析、法源和证据缺口。
- 14个最高人民法院指导性案例的双语教学摘要，保留编号和官方来源。
- 16项业务流程练习，支持初稿、修订和个人自查。

案例英文属于教学译写，不是官方英文判决。自编模拟案与真实指导性案例分别标记。旧案裁判时法律与现行规则分别提示，具体适用仍需核查。

## 使用

可通过GitHub Pages浏览。下载后将全部文件置于同一目录，用现代浏览器打开index.html，也可离线学习。法源外链需要联网。无需安装，无外部CDN依赖。

学习记录只存于当前浏览器，可导出TXT或备份为JSON并在另一设备导入。换浏览器、清除数据或移动离线文件可能影响记录，应定期备份。个人自记进度不等于正式课程成绩。

请勿在学习笔记中填写真实客户、同学或企业的敏感信息。网页不上传作答，不提供全班自动统计；GitHub托管服务自身的日志与条款另行适用。

## 编号

U01—U08对应大纲第1—8次活动，U09—U16对应第10—17次活动。第9次期中考试和第18次期末复习为综合入口，不另算知识单元。

资料核验日期：2026年11月9日。
